# VisionSeek

**Cost-Aware Bilingual Text-to-Video Retrieval**

VisionSeek is a two-stage retrieval system that searches videos with English or
Chinese text. It investigates whether a lightweight learned router can send only
uncertain queries to an expensive temporal reranker while preserving most of the
retrieval-quality gain.

> Project status: Phase 0 — repository and evaluation foundations. No benchmark
> results are reported yet.

## Research Question

Can a learned routing policy reduce reranker usage and end-to-end latency while
retaining at least 95% of the Recall@1 improvement produced by always reranking?

This is a target to test, not a claimed result.

## Planned System

```text
English/Chinese query
        |
        v
Dual encoder + FAISS first-stage retrieval
        |
        v
Confidence features: score margin, entropy, dispersion
        |
        v
Budget-aware router
   |                     |
confident             uncertain
   |                     |
return result       temporal/caption-aware reranker
                           |
                           v
                      final ranking
```

## Core Contributions

1. A reproducible OpenCLIP/InternVideo retrieval baseline.
2. A lightweight query-aware temporal reranker with a frozen video backbone.
3. A learned router trained to predict when reranking is worth its compute cost.
4. English and Chinese evaluation on MSR-VTT and VATEX.
5. Accuracy-latency analysis with PyTorch and ONNX Runtime.

## Evaluation

Retrieval quality:

- Recall@1, Recall@5, Recall@10
- Median rank and mean rank

Efficiency:

- p50 and p95 query latency
- queries per second
- reranker invocation rate
- peak GPU memory
- index size

## Quick Start

The supported development environment is Python 3.12 with a recent CUDA-enabled
PyTorch build.

```powershell
uv venv --python 3.12
.\.venv\Scripts\Activate.ps1
uv sync --extra dev
python scripts/check_environment.py
pytest
python scripts/smoke_test.py
```

The project pins the official CUDA 13.0 PyTorch wheels through `pyproject.toml`.
The project will add OpenCLIP, video decoding, FAISS, and ONNX dependencies only
when their milestone begins.

Large datasets and model caches should be placed outside the repository. Copy
`.env.example` to `.env` and adjust the paths for the local machine.

## Reproducibility Policy

- Every reported number must be generated by a committed configuration.
- Test data must not influence training, routing thresholds, or model selection.
- Results must include hardware, software version, seed, batch size, and precision.
- External implementations and research ideas are documented in
  [REFERENCES.md](REFERENCES.md).
